    SOBRE O CASE

    Código real, limites claros.

    Esta publicação foi preparada a partir dos arquivos versionados de um laboratório local. O histórico foi reiniciado e arquivos de dados e configuração local ficaram de fora. Hash com salt e remoção de campos reduzem exposição, mas dados de saúde continuam sensíveis: qualquer uso com fonte real exige autorização, controle de acesso e revisão de privacidade. A demonstração visual não exibe dados operacionais.
