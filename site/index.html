Laboratório em desenvolvimento

Uma plataforma de dados em camadas para a APS.

Para equipes de engenharia de dados que precisam transformar dados autorizados do e-SUS em tabelas validadas e indicadores rastreáveis para apoiar a gestão da Atenção Primária. Esta página documenta a arquitetura e o estado do código; não representa a interface do dashboard Streamlit.

SEGURANÇA E REPRODUÇÃO

Sem dados operacionais nesta vitrine

Os dados e arquivos locais de saúde não são publicados. Hash com salt e remoção de colunas reduzem exposição, mas não tornam automaticamente anônimos os dados. Use apenas dados sintéticos ou fonte autorizada, com acesso controlado e revisão de privacidade.
